# LocalRoute 원격 DB 적용 기록

2026-10-17, 창업자의 “LocalRoute DB에 적용”, “유료 빼고는 다 적용” 승인으로 지정 프로젝트 `pjdawapasozsrpnrtsfx`에 적용했다. 다른 프로젝트를 사용하지 않았다.

- 저장소 마이그레이션 21개를 적용하고 원격 이력의 이름과 버전을 로컬 파일과 대조했다. MCP가 발급한 적용 버전은 성공한 SQL과 정확한 이름을 확인한 뒤 원래 로컬 버전으로 일치시켰다.
- 원격 공개 테이블 37개 모두 RLS를 활성화했다. `anon`/`authenticated`의 직접 테이블 쓰기와 서비스 전용 RPC 실행을 허용하지 않는다. 회원 쓰기는 서버의 이메일 확인·동의·역할 검증을 거쳐 제한된 서비스 RPC로 처리한다.
- `place-photos` Storage 버킷은 비공개다. 실제 사진은 작성자 권한과 사람의 검토를 거쳐 공개한다.
- 초기 추천을 통한 무료 일정 시연 승인에 따라 `lp_policy`는 `version=starter-preview-v1`, `planning_enabled=true`, `plan_cost=0`, `rewards_enabled=false`로 설정했다. 무료 생성은 월간 LP 발급과 0원 원장 기록도 만들지 않는다. 실제 결제·보상 지급은 비활성이다. `/checkout/test`는 네트워크 결제나 LP 발급 없는 모의 UI다. 예약 요청 모듈은 승인된 HeyYumi 연동의 지원 매장에서만 별도 안내·정보 재확인·명시적 제출 동의를 거쳐 이용한다. 제출은 확정 예약을 의미하지 않는다.
- 원격 이메일 설정은 `mailer_autoconfirm=false`로 확인했다. SMTP·허용 리디렉션·메일 템플릿은 DB 스키마 적용과 별개다. 템플릿 파일 생성만으로 호스팅 메일이 바뀌지는 않는다.
- DB 리전은 `ap-south-1`(인도 뭄바이)다. 국외 이전 고지와 실제 공급자 설정을 일치시켜야 한다.

2026-10-17 최종 통합 담당자 확인: 공개 장소 29곳(최초 충주·성수 26곳 + 을지로 시연 3곳), 운영자 출처 29개다. `place_display_media` 14개는 실제 사진 2개와 AI 참고 이미지 12개로 구분하며, 기존 라이선스 출처 사진 6개를 합쳐 실제 사진은 8개다. 음식 장소 13곳 중 표시 이미지 미등록은 0곳이나, AI 참고 이미지를 실제 해당 장소 사진으로 해석해서는 안 된다. 사용자 제공 사진은 해당 라벨과 개인정보 보호 가공 내역을 표시하며 원본을 공개 배포하지 않는다([가공 기록](FOUNDER_PLACE_PHOTO_PROCESSING.md)). 14:20 KST 조회 당시 독립 추천·동의·LP 원장은 각각 0개였으며, 이는 이후 시점의 수를 단정하는 기록이 아니다. 가짜 계정·독립 추천·방문 이력을 넣지 않았다. 운영자 추천·출처 사진은 기여자의 추천·방문·직접 촬영 증거와 별도다. 원격 스키마/RLS 검증은 독립 PostgreSQL 세션의 LP 경합이나 실제 메일 전달을 대신하지 않는다.

현재 키 연결 확인: Kakao 활성화 후 실제 주소 검색과 자동차 경로 조회가 성공했다. Gemini `gemini-3.1-flash-lite`는 초기의 Zod JSON Schema 거부를 수정한 뒤 실제 장소 후보로 5개 정류장 일정을 생성했고 서버 일정 검증을 통과했다. 이 검사는 개인정보·계정 생성·LP 조작·실제 예약 없이 수행했으며 인증 회원의 DB 저장 완료까지 검증한 것은 아니다. 사용자는 HeyYumi 서비스 연동 허가를 받은 키라고 명시했고 통합 담당자가 검색·예약 승인 플래그를 활성화했다. 실제 장소 검색과 지원 매장 확인, 공식 샌드박스의 제출·상태 조회만 검증했으며 실예약 POST는 수행하지 않았다. 자세한 승인 근거와 미검증 범위는 [현재 출시 상태](LIVE_RELEASE_STATUS.md)에 기록한다.

검증 증거 및 남은 설정은 `SECURITY_REVIEW_HANDOFF.md`, `RELEASE_QA_HANDOFF.md`, `LAUNCH_CONFIG_HANDOFF.md`, `docs/AUTH_EMAIL_SETUP.md`를 함께 참고한다. 독립 리뷰어 소유 보고서는 수정하지 않는다.
