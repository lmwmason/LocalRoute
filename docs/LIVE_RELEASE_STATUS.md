# LocalRoute live release status

2026-10-17 통합 담당자가 보고한 현재 상태와 실행 증거다. 이 문서 정정 작업에서는 원격 설정 변경·DB 조회·배포를 수행하지 않았다.

- 사용자는 지정 LocalRoute DB 적용과 유료 기능을 제외한 연동, 무료 일정 시연, 제공한 장소 사진의 공개 연결을 승인했다. 사용자는 HeyYumi 키가 서비스 연동 허가를 받은 키라고 명시했다. 이는 사용자의 권한 확인 답변이며 운영 계약 전체를 독립 감사했다는 뜻은 아니다.
- 서비스는 https://localroute.vercel.app에 배포됐다. 무료 AI 일정은 0 LP이며 이 흐름은 LP를 발급하거나 차감하지 않는다. 실제 결제와 보상 지급은 비활성이다.
- 통합 담당자 보고: HeyYumi 실제 검색이 HTTP 200으로 카페 2개·성수족발 2개를 반환했다. 하이드미플리즈 을지로의 provider ID는 1185547279이며 yumiReservable=true, channels=yumi를 확인하고 기존 canonical 장소와 연결했다. 연동 및 접근 승인 플래그가 활성화된 지원 매장에 한해 사용자 정보 재확인과 별도 명시적 동의 후 예약 요청 제출 모듈을 제공한다. 제출은 업체 확인 전까지 확정이 아니다.
- 경로/예약 담당자 보고: 공식 X-Map3-Sandbox: 1 헤더를 사용한 POST 1회는 HTTP 200, sandbox=true 및 sbx_r_pending을 반환했고 GET 1회에서 confirmed를 확인했다. 공식 샌드박스는 실제 저장·푸시·SMS를 발생시키지 않는다고 안내한다. 이 결과는 실제 예약 성공의 증거가 아니다. 실예약 POST는 수행하지 않았고 실제 매장 수신·상태 변경·취소 흐름은 미검증이다.
- 이메일 확인 필수 설정은 확인했으나 실제 SMTP 인증 메일 수신과 링크 완료는 미검증이다. 로컬 이메일 템플릿 생성만으로 제공자 템플릿 적용·메일 전달을 보장하지 않는다.
- 전체 검사 실행에서는 typecheck와 lint가 통과했고 테스트 657개 중 656개가 통과했다. 나머지 사진 브라우저 테스트 1개는 15초 시간 제한을 초과했다. 검사 중 HEAD가 422e6a0에서 177dbba로 변경됐으므로 고정 소스 스냅샷의 결과는 아니다. 이후 fixture의 반복 배열 뷰 생성·대용량 IPC 전송만 최적화한 4b7c84e에서 해당 파일 5개 테스트와 담당 lint가 통과했다. 제품 사진 처리 함수·개인정보 검사·시간 제한은 변경하지 않았으며 최신 전체 검사를 다시 수행했다는 뜻은 아니다.
- 공개 장소 29곳, RLS 적용 공개 테이블 37개, 마이그레이션 21개다. 표시 미디어 14개(실제 사진 2개·명시적 AI 참고 이미지 12개)와 기존 라이선스 사진 6개를 구분한다. 실제 사진 합계는 8개이며 음식 장소 13곳의 표시 이미지 미등록은 0곳이다. AI 참고 이미지는 장소의 실제 모습·메뉴 증거가 아니다. 사용자 제공 사진의 인물 흐림·방향 보정·메타데이터 제거는 bdd6eb0 및 [가공 기록](FOUNDER_PLACE_PHOTO_PROCESSING.md)을 따른다. 원본은 커밋·공개 배포하지 않았다.

법적 안내 정정은 기존 선택 예약 흐름의 실제 활성화 상태를 설명한다. 필수 가입 수집 항목이나 동의 범위를 확대하는 변경을 주장하지 않으며 LEGAL_VERSION을 변경하지 않았다. 이번 작업에서는 현재 동의 이력을 다시 조회하지 않았다. 실제 배포 시점과 배포 커밋은 배포 담당자의 별도 기록을 따른다.
